A FEW THOUGHTFUL REMINDERS

Security can be simple.

You don't need to be an expert to make your accounts harder to guess.

01↗

Make it long

Length gives a password more possible combinations to resist guessing. When in doubt, make it longer.

02≠

Keep every password unique

One password per account means a leaked login can't unlock all the others.

03Aa

Add a little variety

Mix uppercase, lowercase, numbers and symbols. This generator includes each group you select.

04⌑

Keep it to yourself

A password is a secret key. Avoid sending it through chat or email, and be aware of clipboard access.

05▤

Use a password manager

A trusted manager can create and remember unique credentials so you don't need to reuse them.

06✓

Turn on another layer

Multi-factor authentication adds another check to help protect your accounts.
